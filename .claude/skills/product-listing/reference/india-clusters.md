## Typical spec keys by category

| Category | Spec keys buyers ask for |
| --- | --- |
| textiles-apparel | Fabric / composition, GSM, width, sizes, colours, print or embroidery, wash, packing |
| agriculture-food | Variety / grade, moisture %, admixture %, colour value or pungency, packing, shelf life, origin |
| machinery-industrial | Capacity, power (kW/HP), voltage / phase, material of construction, dimensions, weight, standards to confirm |
| chemicals-raw-materials | CAS No., assay / purity %, form, appearance, moisture, packing (25 kg bag / 200 L drum), MSDS available |
| construction-building | Size, thickness, grade, finish, water absorption, standard to confirm (IS / ASTM), packing per box |
| electronics-electricals | Rating (W / A / V), IP class, efficiency, material, warranty terms, standard to confirm |
| auto-parts-vehicles | Fits (vehicle / OEM number to confirm), material, finish, tolerance, packing |
| plastics-rubber | Polymer, grade, MFI, colour, dimensions, hardness (Shore A), packing |
| packaging | Board / film type, ply or micron, GSM, size, print colours, load capacity, packing |
| furniture-home | Material, finish, dimensions, knock-down or assembled, carton size, load rating |
| handicrafts-gifts | Material, technique, dimensions, finish, weight, custom logo option, packing |
| gems-jewellery | Metal, purity (hallmarking to confirm), weight, stone type and size, finish |
| pharma-healthcare | Dosage form, strength, pack size, storage. Demo data never makes treatment claims. |

## Price bands

Demo prices are only plausible wholesale ranges, not market quotes. Keep them in the right order of magnitude.

| Product | Demo price band |
| --- | --- |
| Cotton T-shirt | ₹120–260 per piece |
| Ceramic floor tiles | ₹28–70 per sq ft |
| PP woven sack | ₹6–14 per piece |
| Turmeric finger | ₹110–190 per kg |
| Brass décor item | ₹350–2,500 per piece |
| Centrifugal pump (1 HP) | ₹4,500–9,000 per piece |

Bulk chemicals and grains are priced per kg or per tonne, never per piece.
